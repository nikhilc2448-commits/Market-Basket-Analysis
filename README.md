# Market Basket Analysis – Product Association & Cross-Sell Insights

## Objective
To identify products frequently purchased together using Market Basket Analysis and generate association rules for cross-selling recommendations.

## Technologies Used
- Python
- Pandas
- mlxtend
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- Market Basket Optimisation Dataset
- 7501 Transactions
- 120 Unique Products

## Project Workflow
1. Data Extraction
2. Data Cleaning
3. Transaction Encoding
4. Frequent Itemset Generation (Apriori)
5. Association Rule Mining
6. Visualization
7. Business Insights

## Visualizations
- Top Frequent Itemsets
- Support vs Confidence Scatter Plot
- Rule Metrics Heatmap
- Product Relationship Network Graph

## Business Insights
- Cross-selling opportunities
- Product bundling recommendations
- Store layout optimization
- Targeted marketing suggestions
